# [Anti-interference]Based on Convolutional Neural Networks, Automotive Radar Signal Denoising and Interference Reduction[with Python code]

Abstract: Driver assistance systems and automatic vehicles rely on sensors to perceive their environment. A set of heterogeneous sensors is used to perform this task robustly. Among them, radar sensors are indispensable because of their range resolution and the possibility of directly measuring speed. As more radar sensors are deployed on the streets, it becomes necessary to handle mutual interference. In the unregulated car radar frequency bands so far, sensors must be able to detect or even mitigate harmful effects of interference, including reduced detection sensitivity. In this paper, we use Convolutional Neural Networks (CNN) to solve this problem, as CNN is one of the most advanced machine learning tools. We demonstrate that CNNs can find structured information in data while preserving local information, thus achieving superior denoising performance. To achieve this goal, CNN parameters are trained using simulated data and integrated into the car radar signal processing chain. The proposed method is compared with state-of-the-art methods, highlighting its promising performance. Therefore, CNNs can be used as an alternative to traditional signal processing methods for interference mitigation.
Introduction: Radar sensors are key elements in current driver assistance systems and autonomous driving applications. Currently, Frequency Modulated Continuous Wave (FMCW)/Linear Frequency Modulation Sequence (CS) radar is a mainstream radar technology. They share an unregulated spectrum and transmit linear chirped signal sequences. The requirement for fine range resolution requires larger radio frequency (RF) transmission bandwidth, and the number of deployed sensors is also increasing. Thus, mutual interference between radar sensors becomes increasingly likely. The most common form of mutual interference is non-coherent interference [1], where radar sensors with different emission signal parameters interfere with each other. This leads to time-limited broadband interference in the baseband signal, mainly affecting the target detection sensitivity [2]. Therefore, interference mitigation is a critical part of the current and future safety environments for the use of radar sensors.
Several conventional signal processing algorithms have been proposed to mitigate interference. The most fundamental method is to zero out the detected interfered samples. In [3], slow time nonlinear filtering is performed to remove interference. In [4], a different approach was introduced, which uses Fourier transform and threshold processing iteratively to reconstruct useful signals [5]. Interference components of the signal can be estimated and subtracted, as in [6]. Additionally, beamforming can be used to reduce the impact of interference from specific directions [7]. In [8], some machine learning techniques were discussed in the context of interference detection and classification. However, no explicit machine learning methods for interference mitigation have been proposed in the context of interference alleviation.
In this paper, we use neural networks (NN) as a powerful machine learning method to alleviate interference. Specifically, convolutional NN (CNN) are employed. They can learn local patterns by considering nearby inputs and identify them throughout the data signal. This structure is also beneficial for spectral graph representations. Moreover, compared to fully connected NN, CNN require relatively few learnable parameters, making them more suitable for deployment on resource-constrained systems such as chip-level integration. We will show how dual channel representations of complex frequency spectrum data using two different points in the processing chain can be used as network inputs.
Since automotive radar is a safety-critical application, certain requirements must be met for interference suppression and signal denoising algorithms. Besides sufficient noise suppression, the processing should not produce phantoms that could lead to false detection (multiple objects). We address these issues by using detailed performance comparisons in Monte Carlo simulations evaluating various application-related measures [10].
The main contributions of this paper are:
·We demonstrate the ability to denoise radar signals with a specific CNN architecture.
·We use application-related performance metrics to compare with state-of-the-art technologies.
·We show that it is possible to achieve excellent denoising levels, thereby improving detection sensitivity.

The proposed method, as shown in Figure 1, illustrates the traditional FMCW/CS radar's distance Doppler (RD) processing chain. First, the radar sensor performs measurements by transmitting linearly modulated linear frequency modulation (LFM) signals (also known as ramps). For each ramp, the received object reflection is then mixed with the transmitted signal, i.e., multiplied. In this way, the corresponding time delay and thus the distance information are converted into a corresponding constant frequency sine curve. The mixed signal is limited by the receiver intermediate frequency (IF) bandwidth, hence referred to as IF signal. The rate of the slope-based linear phase change of the received IF signal is evaluated to estimate the velocity (Doppler) information. More detailed descriptions and mathematical derivations of these principles can be found in [11] and [12].
The proposed denoising and interference suppression network architecture is based on CNN. We investigated two different denoising methods, RPD and RDD, as shown in Figure 1. Additionally, we used an input channel for the logarithmic amplitude spectrum (LMS) or two channels, namely the real and imaginary parts of the complex valued spectrum (RIS). The fundamental goal remains the same, i.e., reducing the impact of noise and interference so that objects can be detected reliably with high sensitivity.
The network structure consists entirely of convolutional layers. The first layer employs convolution operations and ReLU [14] activation functions, while subsequent layers include batch normalization [15], convolution operations, and ReLU non-linearities, except for the last layer which uses a linear activation function.
The model architectures of RPD and RDD differ slightly. RPD is applied to one-dimensional data (1×N), thus using a one-dimensional kernel. RDD has two-dimensional input samples, namely N ×M blocks, and uses square kernels. In both methods, zero padding is used at the boundary values to ensure that the input and output of each layer have the same dimensionality.

LMS vs. RIS Denoising
We compared the denoising using LMS and RIS inputs, focusing on performance, memory requirements, and application relevance. Denoising LMS can be used for target detection tasks but cannot be used for further processing based on complex spectral values because phase information is lost. In RDLMS denoising, raw data without NN processing can be used for further AS computations. On the other hand, denoising spectra can be directly used for further processing through RIS inputs, thus allowing for RD calculations or AS computations in RD denoising.
For example, an RDD with 6 layers and 16 kernels of size 3×3 requires 10002 parameters from RIS and 9713 parameters from LMS inputs, corresponding to a reduction of only 2.8%. For a similar architecture of RPD with 8 layers and 8 kernels of size 1×41, it requires 17210 parameters for RIS denoising. For more detailed performance comparisons, see Section V.
Data Processing: Prior to model training and evaluation, standardize data samples to enhance learning capabilities and model robustness. Two methods are studied: Zero Mean Unit Variance Scaling (ZMUVS) and Complex Standard Scaling (CSS) [16]. In these methods, complex data points are normalized to zero mean, while for ZMUVS, they are scaled to unit variance, and for CSS, the data points are scaled to a standard normal complex distribution using the inverse of the square root of the covariance matrix of real and imaginary values.
Loss Function: The loss function defines the similarity between the output of the neural network and its target, thereby representing the learning objective.
· Mean Squared Error (MSE) is calculated by summing the real and imaginary parts of the values from the complex spectrum graph.
· Signal-to-Interference-plus-Noise Ratio (SINR) is the ratio of signal power to noise floor, where the noise floor is provided by both noise and interference.
· Weighted MSE is determined as a convex combination of the MSE of the complex spectrum and the amplitude and phase of the object peak.
